Bank Marketing Customer Purchase Prediction (Task-03)
Project Objective
To build a decision tree classifier that predicts whether a customer will subscribe to a product or service (term deposit) based on their demographic and behavioral data.

Dataset
Source: UCI Machine Learning Repository - Bank Marketing Dataset.

Format: CSV

Methodology
Tool Used: Power BI

Visual Analysis: Implemented a Decomposition Tree to represent the decision-making logic of the classifier.

Key Variables Analyzed: Marital status, Housing, Job, and Education.

Key Insights
Successfully visualized the hierarchical path of customer decision-making.

Identified high-conversion segments based on demographic combinations.

Provided data-driven insights to optimize future marketing campaigns.
